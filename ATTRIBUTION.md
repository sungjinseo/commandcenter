## Web UI

The web UI (`internal/ui/static/`) has no third-party files: no fonts, no icon sets, no
frameworks. Its icons are drawn as SVG paths in `internal/ui/static/util.js` after the
project's own design concept. It uses no logos, icons or
stylesheets from other products.
